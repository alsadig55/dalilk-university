# دليلك الجامعي — نسخة احترافية

نسخة واجهة احترافية مبنية على بيانات ملف نتيجة القبول للبكالريوس 2024م.

## التشغيل
افتح `index.html` مباشرة أو ارفع `index.html` و`data.js` إلى الاستضافة نفسها.

## ملاحظات
- البيانات مستخرجة من ملف PDF المرفق.
- الولاية والمساق ونوع المنافسة لا تتم إضافتها إلا إذا كانت موجودة صراحة في المصدر.
- يمكن لاحقًا إضافة لوحة تحكم وتحديث البيانات من دليل جديد.
